### 🚀 CommitStream — Real-Time Git Merge & Collaboration Workspace

*A dark-themed, real-time collaborative MERN application built to streamline development workflows, predict & resolve merge conflicts, and coordinate remote engineering teams.*

</div>

| Feature | Description |
|---|---|
| 🔄 **Real-Time Collaboration** | Powered by **Socket.io** for instant team chat, discussions, and live dashboard sync |
| 🤖 **AI Codebase Chatbot** | Parses project files to answer developer queries, explain logic, and suggest optimizations |
| ⚡ **Merge Conflict Resolution** | Dedicated workspace to predict, view, and resolve Git merge conflicts |
| 📰 **Smart Blog Aggregator** | Scrapes developer news, rewrites it with AI for readability, and surfaces it in a live feed |
| 📋 **Integrated Kanban Board** | Task management mapped directly to GitHub branches & pull request status |
| 🔑 **Secure GitHub OAuth** | Robust OAuth flow for developers to securely link and access repositories |

**Tech Used:** `React.js` `Node.js` `Express.js` `MongoDB` `Socket.io` `Tailwind CSS` `AI/LLM API` `Web Scraping` `GitHub REST API`
